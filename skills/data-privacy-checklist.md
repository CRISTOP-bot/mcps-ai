# Skill: Privacidad

- [ ] ¿Realmente necesitas el dato?
- [ ] ¿Lo puedes anonimizar/seudonimizar?
- [ ] ¿Dónde se guarda? ¿Cifrado en reposo?
- [ ] ¿Cuánto tiempo lo retienes?
- [ ] ¿Quién tiene acceso?
- [ ] ¿El usuario puede pedir borrado?
