# Skill: Reading list

## Flujo
1. Capturar URL/título en lista (Notion o archivo)
2. Clasificar: técnica / noticias / referencia / divertimento
3. Al leer: extraer 3 ideas + fuente
4. Archivar con resumen de 1 línea
