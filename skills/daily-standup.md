# Skill: Daily standup

## Formato
1. ¿Qué hice ayer?
2. ¿Qué haré hoy?
3. ¿Bloqueos?

## Cómo ayudar
- Revisar git log de ayer para reconstruir
- Listar PRs abiertos y CI status
- Recordar reuniones del día (calendar)
