# Skill: Accesibilidad

## Esenciales
- Contraste ≥ 4.5:1 texto normal
- Alt en imágenes; aria-label en iconos
- Todo clickeable con teclado (focus visible)
- Semántica HTML antes que ARIA
- prefers-reduced-motion respetado
