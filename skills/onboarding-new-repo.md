# Skill: Onboarding repo

## Checklist
1. README + CONTRIBUTING
2. Setup: copiar .env.example, instalar deps
3. Build/test que pase en limpio
4. Issue bueno para primer PR: docs o tests
5. Preguntar por convenciones (ramas, commits)
