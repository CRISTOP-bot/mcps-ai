# Skill: Task management

## Sistema simple
1. **Capturar** todo en una lista (Notion/inbox)
2. **Procesar** 2x/día: hacer (2min) / agendar / delegar / borrar
3. **Priorizar**: Eisenhower (urgente/importante)

## Con MCPs
- Tareas → entradas en Notion database
- Recordatorios → Telegram
- Notas → filesystem skills/
