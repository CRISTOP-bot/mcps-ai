# Skill: Ingeniería de prompts

## Estructura efectiva
1. Rol: "Eres un experto en X"
2. Contexto: "El usuario usa Y"
3. Tarea: "Haz Z"
4. Formato: "Responde con JSON: ..."
5. Ejemplos: "Así: ..."

## Técnicas
- Few-shot: 2-3 ejemplos
- Chain of thought: "Piensa paso a paso"
- Structured output: JSON schema
- Negative prompting: "No hagas X"

## Para agentes
- Ser específico
- Dar contexto del usuario
- Pedir confirmación en acciones destructivas
