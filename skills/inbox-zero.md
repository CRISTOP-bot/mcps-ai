# Skill: Inbox zero

## Proceso
1. `gmail_get_unread()` → empezar por lo más viejo o más reciente
2. Decidir: responder / archivar / borrar / etiquetar
3. Plantillas para respuestas repetidas
4. Unsubscribe de newsletters basura (con confirmación)
5. `gmail_archive` al terminar
