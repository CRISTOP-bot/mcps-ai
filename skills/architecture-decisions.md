# Skill: ADRs

## Formato
```
# ADR 001: Título
Estado: aceptado | propuesto | deprecado
Contexto: por qué
Decisión: qué
Consecuencias: trade-offs
```

## Cuándo escribir uno
- Elección de framework/protocolo/DB
- Cambios que afectan a varios componentes
- Algo que te obligarás a recordar dentro de 6 meses
