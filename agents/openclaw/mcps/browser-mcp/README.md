# Browser MCP (openclaw)

Interactive browser control via Playwright.

## Tools (17)
- browser_navigate, browser_click, browser_fill, browser_type, browser_press
- browser_get_text, browser_get_html, browser_screenshot, browser_evaluate
- browser_wait, browser_select, browser_scroll, browser_back/forward/reload
- browser_get_links, browser_close

## Setup
```bash
uv sync
uv run playwright install chromium
```
