Features

Real tools for real work.

Not toy demos. Actual integrations — Telegram, WhatsApp, Gmail, Minecraft, GitHub, Discord, Spotify, Slack, Notion, Home Assistant, the filesystem, system metrics, the web, and a full browser.

Telegram

32 tools

Control your AI from Telegram — 24/7 worker, auto-model switching, screen-lock safe, progress streaming.

WhatsApp

12 tools

Go bridge (whatsmeow) + Python server. Send messages, files and media to any contact or group.

Minecraft

21 tools

Full RCON control — admin commands, weather, teleport, difficulty, give/clear items, spawn entities.

Gmail

19 tools

Read, send, search, archive, star and thread emails via the Gmail API with OAuth2.

Filesystem

14 tools

Read, write, search, hash, move and delete files — confined to specific directories for safety.

System

18 tools

CPU, memory, disk, processes, network, ports, logs, battery and temperature — cross-platform.

Web

4 tools

Search Bing without an API key. Fetch pages as text. News. Weather for any city.

Browser

17 tools

Control Chrome/Chromium via Playwright — navigate, click, type, screenshot, execute JavaScript.

GitHub

16 tools

Repos, issues, pull requests, code & issue search, releases, and gists — token or gh CLI auth.

Discord

11 tools

Send and manage messages, reactions, channels, members and webhooks via a Discord bot.

Spotify

14 tools

Search, playback control, volume, queue, playlists and devices with OAuth refresh-token auth.

Slack

11 tools

Messages, DMs, channels, history, users, reactions and pins — Slack bot token (xoxb).

Notion

11 tools

Search, pages, databases, blocks and users through a Notion internal integration.

Home Assistant

11 tools

States, services, domains, history and events for the smart home — long-lived access token.

Install

One command. Zero config guesswork.

npx mcps-ai install

Detects your installed agents, clones the repo, installs Python dependencies, prompts for credentials, writes configs, and backs up anything it touches.

npm / npx

npx mcps-ai install

Manual clone

git clone https://github.com/CRISTOP-bot/mcps-ai.git
cd mcps-ai
./setup.sh

Usage

Tell your agent what you want. It calls the right tool.

“List my unread Gmail”

→ gmail_get_unread

“Give @Steve 5 diamonds in Minecraft”

→ mc_give

“Send ‘done’ to Cristopher on Telegram”

→ telegram.send_message

“Find Python files over 1 MB”

→ fs_search_files

“Show me CPU usage now”

→ sys_cpu

“Weather in Madrid”

→ web_weather
